# 食物分类与风险提示标准

## 目标

确认页只使用食物类别，不把“蛋白质、碳水化合物、脂肪”等营养素与食物类别并列。分析页再根据食物类别解释主食、蛋白质来源和蔬菜等餐食结构。

分类参考《中国居民平衡膳食餐盘（2022）》与《中国居民膳食指南（2022）》的食物分组思路，并为图片识别确认场景增加“其他”和“无法判断”两个产品兜底标签。

## 可选类别

- 谷薯类
- 鱼禽肉蛋类
- 奶类
- 大豆坚果类
- 蔬菜
- 水果
- 其他
- 无法判断

一道食物可以对应多个类别。例如：

- 牛肉面：谷薯类、鱼禽肉蛋类。
- 蛋炒饭：谷薯类、鱼禽肉蛋类。
- 番茄炒蛋：鱼禽肉蛋类、蔬菜。
- 豆腐青菜：大豆坚果类、蔬菜。

“混合菜”不作为与上述食物类别并列的标签。无法得到充分依据时使用“无法判断”，不得为了结构完整而强制归类。

## 分析映射

- 谷薯类 → 主食依据。
- 鱼禽肉蛋类、奶类、大豆坚果类 → 蛋白质来源依据。
- 蔬菜 → 蔬菜依据。
- 水果 → 水果构成。
- 其他、无法判断 → 不计入主食、蛋白质来源或蔬菜的完整性判断。

## 盐、油脂和添加糖提醒

提醒只由确认后的食物名称和明确烹饪方式触发，使用“可能偏多”的风险语言，不估算具体克数或毫克数。

- 腌制、熏制、腊味、咸菜、方便面等明确线索，可触发“盐可能偏多”。
- 油炸、肥肉、奶油等明确线索，可触发“油脂可能偏多”。
- 奶茶、含糖饮料、蛋糕和甜点等明确线索，可触发“添加糖可能偏多”。
- 单独出现“炒”或图片表面发亮，不足以触发油脂提醒。
- 没有明确线索时，不显示该模块。
